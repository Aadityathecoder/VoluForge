# VoluForge SwiftUI phone preview

This is a native SwiftUI preview of VoluForge’s student dashboard, fellowship cohort, squad missions, and profile. All displayed names, hours, and outcomes are fictional sample data. Buttons change local preview state only; this preview does not sign in to or write to the VoluForge backend.

## Run on your iPhone

1. Open `VoluForge.xcodeproj` in Xcode on a Mac.
2. Select the **VoluForge** app target, then choose your Personal Team under **Signing & Capabilities**.
3. Connect your iPhone, select it as the run destination, and press **Run**.

The project targets iOS 17 and uses only SwiftUI. No package install or API keys are required. The project source is also included in the VoluForge GitHub repository under `ios/VoluForge`.
